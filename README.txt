나의 가계부 v1.0

사용 방법
1. 이 폴더의 파일을 모두 HTTPS 정적 웹 호스팅에 올립니다 (예: GitHub Pages).
2. 안드로이드 Chrome에서 해당 HTTPS 주소를 엽니다.
3. 브라우저 메뉴의 '홈 화면에 추가' 또는 '앱 설치'를 선택합니다.
4. 설치 후에는 오프라인에서 기록할 수 있습니다.

참고: index.html을 file:// 경로로 직접 여는 방식은 PWA 설치와 오프라인 캐싱이 작동하지 않습니다.
데이터는 접속한 브라우저/도메인에 저장됩니다. 주소나 도메인을 바꾸면 기존 데이터가 자동 이전되지 않습니다.
설정 > 백업 파일 저장 기능으로 정기적으로 JSON 백업을 보관하세요.
